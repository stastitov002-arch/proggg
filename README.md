# 4060-site — сайт студии 40/60 Design

Статический сайт на GitHub Pages: `4060design.ru`.
HTML-страницы **генерируются** из Markdown и JSON скриптом `build.py`,
поэтому шапка, подвал и типографика одинаковы на всех страницах, а новые
страницы проектов и статей появляются автоматически.

```
_projects/*.md      проекты портфолио (YAML front matter)
_articles/*.md      статьи блога (front matter + Markdown)
_content/*.md       страница «Стандарты» и «Требования к мебели»
_knowledge/         публичная техническая библиотека и источники знаний
_content/pages/     тела страниц «О нас», «Партнёрам», «Гарантия», «404»
_data/site.json     общие тексты и контакты (переопределяются на клиенте)
build.py            генератор страниц
css/site.css        единая дизайн-система
js/site.js          шапка, модалки, формы, фильтры, галерея
bot/                Telegram-бот-редактор (Cloudflare Worker + DeepSeek)
```

## Сборка

```bash
python build.py
```

Скрипт перезаписывает `index.html`, `portfolio.html`, `articles.html`,
`standards.html`, `requirements.html`, `about.html`, `warranty.html`,
`partners.html`, `404.html`, страницы `portfolio/*.html`, `articles/*.html`,
превью черновиков `preview/*.html`, страницы инженерной базы и технической библиотеки, а также `sitemap.xml` и `robots.txt`.
Устаревшие сгенерированные страницы удаляются автоматически.

Python 3.10+, сторонних библиотек не требуется.

## Как добавить контент

Три равноправных способа — все они пишут одни и те же файлы:

1. **CMS в браузере** — `/admin/` (см. ниже). Визуальный редактор: тексты, блоки,
   вопросы, проекты, статьи, фотографии.
2. **Telegram-бот** (`bot/README.md`) — фото, описание, ИИ приводит к стандарту,
   превью, публикация.
3. **Вручную** — добавить `.md` в `_projects`, `_articles` или `_knowledge/<раздел>` и запушить. Для технической статьи укажите в YAML-полях `slug`, `title`, `description`, `category`, `status`, `version`, `checked`.

После любого пуша GitHub Actions запускает `build.py` и коммитит готовые
HTML-страницы (`[skip ci]`), GitHub Pages публикует их через 1–2 минуты.

## CMS `/admin/`

Своя админка, которая повторяет сайт: `admin/index.html` + `cms.js` + `cms.css`.
Работает как статическая страница и общается с GitHub API напрямую.

**Вход.** Нужен fine-grained token с правом **Contents: Read and write** на репозиторий.
Токен хранится только в localStorage браузера. Интерфейс без токена можно посмотреть
по адресу `/admin/?preview=1` (только чтение).

> Если сайт опубликован на GitHub Pages, `/admin/` уже доступен.
> Локально: `python -m http.server` из корня сайта и открыть `http://localhost:8000/admin/`.

**Что умеет:**

- **Главная** — форма по всем блокам: первый экран, портфолио, «Проект под ключ»
  (карточки добавляются/удаляются/меняются местами), «Этапы работы» (10 шагов),
  производство, частые вопросы (добавить/удалить вопрос), CTA, статьи, стандарты, контакты.
- **Портфолио** — список проектов: добавить, изменить, удалить, продублировать slug,
  отметить «на главной», поставить черновик. В редакторе: материалы и планировка
  мультивыбором, цена, описание, загрузка/замена/удаление фото, выбор обложки.
- **Статьи** — список и редактор: заголовки, description, обложка, теги, ключи,
  Markdown-текст, черновик, удаление.
- **Страницы** — `_content/standards.md` и `_content/requirements.md` целиком.
- **Фотографии** — замена ключевых картинок сайта (первый экран, баннер портфолио,
  фон CTA, шоурум, OG-обложка).
- **Визуальный режим** — страница сайта в превью: кликаете по тексту (он обведён
  пунктиром), правите в панели справа, сохраняете. Значения уходят в `_data/site.json`.

Каждое сохранение — отдельный коммит; сайт пересобирается автоматически.

## Поведение интерфейса

- **Фильтры портфолио** — четыре селекта (материал, тип, планировка, бюджет) плюс
  «Только с островом». Выбор запоминается в sessionStorage и в адресе страницы,
  поэтому при переходе в проект и возврате фильтры сохраняются. На странице проекта
  есть кнопка «← Ко всем проектам», которая возвращает назад по истории.
- **Cookie-уведомление** — показывается один раз, согласие хранится в localStorage.
- **«Проект под ключ»** — карточки со скруглениями, иконками и hover-анимацией.
- **«Этапы работы»** — путь клиента: вертикальная линия, круглые номера и карточки
  этапов с каскадным появлением.

Старая CMS на Decap осталась как резерв: `/admin/decap.html` + `admin/config.yml`.

### Проект портфолио

```yaml
---
slug: kitchen-walnut-gold-premium
title: Кухня из шпона
featured: true
type: Кухня
layout: Угловая, С островом
material:
  - Шпон
  - Эмаль
price: 1500000
description: Фасады из натурального шпона, столешница — кварцевый агломерат.
cover: /images/uploads/photo_1.jpg
gallery:
  - /images/uploads/photo_2.jpg
facades: Шпон, эмаль
countertop: Светлый кварцевый агломерат
hardware: Blum
equipment: ''
draft: false
---
```

`material` и `layout` — списки. Проект с двумя материалами появляется
**в обоих** фильтрах: это ключевое исправление фильтрации.

### Статья

```yaml
---
title: Сколько стоит кухня на заказ в Москве в 2026 году
h1: Сколько стоит кухня на заказ в Москве в 2026 году
description: Meta description 140–160 символов
lead: Короткий ответ под H1
cover: images/uploads/photo.jpg
category: Цены
tags: [цены, кухни]
keywords: [сколько стоит кухня на заказ]
date: 2026-11-18
draft: false
slug: skolko-stoit-kuhnya-na-zakaz-2026
---
```

Тело — Markdown. Блок «Частые вопросы» собирается из `## Частые вопросы` +
`### Вопрос`, и из него автоматически генерируется микроразметка FAQPage.

## Стандарт статьи

Структура, которую требует бот и в которую приводит текст ИИ:

- H1 + «Короткий ответ» (лид);
- сколько стоят кухни разных размеров — реальные проекты и цены;
- из чего складывается стоимость: фасады, корпус, фурнитура, столешница, сложность;
- как выглядит кухня за 300 000 ₽ и за 500 000 ₽ — реальные проекты;
- как снизить стоимость и на чём экономить не стоит;
- частые вопросы (H3) + CTA (добавляется шаблоном автоматически).

Правило 40/60: 40% теории, 60% фактов — цен, комплектаций, расчётов и фото.

## Дизайн-система

- **Заголовки — Cormorant Garamond.** Архитектурная антиква с контрастом толщин,
  крупный кегль, настоящий курсив для акцентных слов («живут», «под ключ»).
- **Текст и интерфейс — Manrope.** Наклон — синтетический курсив для акцентов.
- **Палитра:** тёмный фон `#0d0c0d`, золото `#c8a572`, зелёный `#0c160e`.
- **Логотип:** фавикон-эмблема (`images/brand-mark-128.png`, вырезана из
  `web-app-manifest-512x512.png`) + текстовая часть «40/60».
- Шапка и подвал — общие функции `header()` / `footer()` в `build.py`,
  поэтому физически не могут отличаться на разных страницах.
- Блок «Отправьте размеры» идёт с фоновым фото (`images/cta-bg.jpg`),
  заменяется в CMS на вкладке «Фотографии».

## Публикация

Сайт обслуживается GitHub Pages из ветки `main` (файл `.nojekyll` отключает Jekyll).
Домен — `CNAME` → `4060design.ru`. Деплой — автоматический после пуша.
