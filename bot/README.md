# Telegram-бот-редактор 40/60 Design

Бот публикует статьи и проекты портфолио на сайт: принимает фото и текст, приводит их
к стандарту через DeepSeek, показывает превью и по кнопке коммитит в GitHub.
GitHub Actions пересобирает сайт — новая страница появляется за 1–2 минуты.

```
Telegram  →  Cloudflare Worker  →  GitHub (_articles / _projects)  →  Actions  →  сайт
                    ↓
                 DeepSeek API
```

---

## 1. Что нужно один раз завести

| Что | Где взять | Куда положить |
|---|---|---|
| Токен бота | @BotFather → `/newbot` | секрет `TG_TOKEN` |
| Cloudflare-аккаунт | dash.cloudflare.com | — |
| GitHub-токен | Settings → Developer settings → Fine-grained tokens | секрет `GITHUB_TOKEN` |
| Ключ DeepSeek | platform.deepseek.com → API keys | секрет `DEEPSEEK_KEY` |
| Свой Telegram id | бот, команда `/id` | секрет `ADMIN_IDS` |

### GitHub-токен

Fine-grained token, доступ только к репозиторию `4060-site`:

- **Contents: Read and write** (коммиты файлов и фото);
- **Metadata: Read** (обязательно, ставится автоматически).

Больше ничего не нужно.

## 2. Деплой воркера

```bash
npm i -g wrangler
wrangler login

cd bot
wrangler kv namespace create BOT
# скопировать id в wrangler.toml → [[kv_namespaces]] → id

wrangler secret put TG_TOKEN
wrangler secret put TG_SECRET        # придумайте длинную строку
wrangler secret put ADMIN_IDS        # 123456789,987654321
wrangler secret put GITHUB_TOKEN
wrangler secret put DEEPSEEK_KEY

wrangler deploy
```

В ответе будет URL вида `https://4060-bot.<ваш-поддомен>.workers.dev`.

### Вебхук

```bash
curl "https://api.telegram.org/bot<TG_TOKEN>/setWebhook" \
  -H "content-type: application/json" \
  -d '{
    "url": "https://4060-bot.<ваш-поддомен>.workers.dev/",
    "secret_token": "<TG_SECRET>",
    "allowed_updates": ["message","callback_query"]
  }'
```

Проверка: `https://4060-bot.<поддомен>.workers.dev/health` → `{"ok":true}`.

## 3. Как пользоваться

### Статья

1. **📝 Новая статья** → пришлите тему и ключевые запросы.
2. Присылайте **факты**: цены, сметы, комплектации, случаи с объектов, ограничения.
   Можно отправлять фото — они станут иллюстрациями.
3. **🚀 Отправить в обработку** — ИИ пишет статью по стандарту
   (короткий ответ → цены → из чего складывается → примеры за 300 000 и 500 000 ₽ →
   как сэкономить → на чём не стоит → частые вопросы).
4. Бот показывает структуру, объём и список **«ИИ просит уточнить»** — если фактов не хватило.
5. Кнопки: **📄 Открыть превью** · **✅ Опубликовать** · **🔁 Переписать** ·
   **✏️ Дать правки** · **❌ Отклонить**.

Черновик коммитится с `draft: true` — страница живёт по адресу
`/preview/<slug>.html`, закрыта от индексации и не попадает в список статей.
Публикация переключает флаг и удаляет превью.

### Проект портфолио

1. **🖼 Новый проект** → 3–5 фото → **Далее**.
2. Название → материалы фасадов (мультивыбор) → планировка (мультивыбор) → цена.
3. Описание — можно вставить пост из Telegram-канала как есть.
4. ИИ приводит текст к стандарту портфолио и говорит, чего не хватает.
5. **✅ Опубликовать** → фото уезжают в `images/uploads/`, карточка в `_projects/`.

Проект с двумя материалами (например, «Шпон» + «Эмаль») автоматически попадает
в оба фильтра портфолио — это и есть главное исправление фильтрации.

### Промпты

**⚙️ Промпты** → «Изменить промпт статьи» → пришлите текст одним сообщением.
Промпт сохраняется в KV и дальше используется для всех материалов.
«Сбросить к заводским» возвращает версию из `bot/prompts.js`.

Заводские промпты лежат в `bot/prompts.js` — там же редактируются, если нужно
изменить стандарт для всех сразу.

## 4. Что бот пишет в репозиторий

```
_articles/<slug>.md      статья (front matter + markdown)
_projects/<slug>.md      проект (front matter в формате CMS)
images/articles/*.jpg    фото статей
images/uploads/*.jpg     фото проектов
```

Формат совпадает с тем, что редактирует CMS в `/admin` — можно править в обоих местах.

---

## 5. Ограничения и нюансы

- Фото хранятся по `file_id` Telegram и скачиваются в момент публикации. Если фото
  удалено из чата — загрузите заново.
- `MAX_PHOTOS = 6`, минимум для проекта — 3.
- Состояние диалога живёт 14 дней, затем выбрасывается из KV.
- Если `ADMIN_IDS` пустой — бот пускает всех. Настройте до передачи бота заказчику.
- Ошибка DeepSeek видна в боте текстом; повтор — кнопкой «Повторить».
- Превью появляется не мгновенно: сначала коммит, потом сборка Actions (~1 мин).

## 6. Локальная проверка

```bash
wrangler dev          # поднимает воркер на localhost
curl http://localhost:8787/health
```

Для локальной отладки вебхука удобно использовать ngrok и `setWebhook` на его адрес.
